# Lab 5.1 – Übung: Was ist ein Agent?

**Ändert die Nordwind-Projektbasis?** Nein — die Einordnung begründet, warum in Lab 5.2 ein Agent für die IT-Fragen entsteht.

## Ausgangslage

Nordwind Consulting überlegt, wo ein eigener Agent hilft. Die Ticketauswertung aus Lab 4.1 liegt vor: VPN ist die häufigste Ticketkategorie. Drei Fälle stehen zur Wahl; jeder bekommt genau eine Einordnung aus der Tabelle „Wann lohnt sich ein Agent?" in der Theorie.

## Aufgaben

1. Lies die drei Fälle im Abschnitt „Quiz".
2. Wähle je Fall eine Antwort A, B oder C.
3. Notiere zu jeder Antwort das Merkmal aus der Tabelle „Wann lohnt sich ein Agent?", das den Ausschlag gibt.

## Quiz

**1. Der interne IT-Support bekommt jeden Monat Dutzende Fragen zur VPN-Einrichtung. Die Antworten stehen in der IT-Richtlinie.**

- A: Agent lohnt sich
- B: normaler Prompt reicht
- C: gar nicht an KI geben

**2. Die Projektleitung möchte eine 40-seitige Ausschreibung der Stadtwerke Nordhafen einmalig in fünf Punkten zusammenfassen.**

- A: Agent lohnt sich
- B: normaler Prompt reicht
- C: gar nicht an KI geben

**3. Die Personalabteilung möchte 30 Bewerbungen für eine offene Stelle von Copilot in eine Rangfolge bringen lassen.**

- A: Agent lohnt sich
- B: normaler Prompt reicht
- C: gar nicht an KI geben

## Checkpoint

- Jede der drei Fragen hat genau eine Antwort.
- Zu jeder Antwort steht ein Merkmal aus der Theorie-Tabelle.

## Abschlusskriterien

- Alle drei Einordnungen sind begründet und mit der Lösung abgeglichen.

## Erweiterung

Notiere einen wiederkehrenden Fall aus dem eigenen Arbeitsalltag und prüfe ihn mit den Merkmalen aus der Tabelle: wiederkehrend, gleiche Quelle, klare Regeln, keine Bewertung von Personen.

## Fallback

Ohne Quizwerkzeug: Antworten auf Papier oder in einer Notiz festhalten und mit der Lösung vergleichen. Einschränkung: kein Gesamtergebnis der Gruppe.
