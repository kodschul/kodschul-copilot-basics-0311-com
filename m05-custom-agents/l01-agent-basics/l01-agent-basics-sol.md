# Lab 5.1 – Lösung: Was ist ein Agent?

## Aufgabe 1: Fälle lesen

Die drei Fälle decken je eine Einordnung ab: wiederkehrende Standardfrage, einmalige Aufgabe, Entscheidung über Menschen.

## Aufgabe 2: Antworten

| Frage | Antwort | Erklärung |
| ----- | ------- | --------- |
| 1. VPN-Fragen | **A: Agent lohnt sich** | Die Frage kommt jeden Monat wieder, die Antwort steht immer in derselben Quelle (IT-Richtlinie), die Regeln sind klar. |
| 2. Ausschreibung zusammenfassen | **B: normaler Prompt reicht** | Einmalige Aufgabe mit einer einzigen Datei; ein Prompt nach der Formel aus Lab 1.2 mit `/`-Referenz genügt. |
| 3. Bewerbungen ranken | **C: gar nicht an KI geben** | Eine Rangfolge von Bewerbungen ist eine Bewertung von Personen mit Folgen für Einzelne; sie bleibt beim Menschen. |

## Aufgabe 3: Ausschlaggebende Merkmale

| Frage | Merkmal |
| ----- | ------- |
| 1 | wiederkehrend, viele Fragende, gleiche Quelle |
| 2 | einmalig, Quelle gilt nur für diesen Fall |
| 3 | Entscheidung über Menschen, Ermessen, hohe Folgen für Einzelne |

## Erweiterung

Beispiel: „Fragen neuer Mitarbeitender zur Reisekostenabrechnung" ist wiederkehrend, hat eine feste Quelle (Reiserichtlinie) und klare Regeln: ein Agent lohnt sich. „Ein Arbeitszeugnis formulieren und bewerten lassen" betrifft die Bewertung einer Person und gehört nicht an KI.

## Fallback

Die Antworten oben gelten unverändert; es fehlt nur der Vergleich mit dem Gruppenergebnis.
