# Microsoft 365 Copilot kompakt – Möglichkeiten entdecken und direkt anwenden

**½-Tag-Workshop** · Office/Business · Deutsch

</div>

---

Teilnehmerunterlagen des Kurses **„Microsoft 365 Copilot kompakt – Möglichkeiten entdecken und direkt anwenden"**. Im Szenario Nordwind Consulting entsteht eine Kette aus Mailantwort, Aufgabenliste, Statusbericht, Präsentation und Ticketauswertung; am Ende steht ein eigener Agent „Nordwind IT-Helfer", dessen Anweisung Copilot selbst entworfen hat.

Jedes Lab besteht aus drei Dateien: Theorie (`-thx.md`), Übung (`-exc.md`) und Lösung (`-sol.md`). Alle Prompts zum Kopieren stehen in [`prompt-karten.md`](prompt-karten.md), alle Quizfragen mit Lösung zum Wiederholen nach dem Kurs in [`quiz-fragen.md`](quiz-fragen.md).

## Auf einen Blick

| | |
| --- | --- |
| **Dauer** | ½ Tag (4 Stunden) |
| **Zielgruppe** | Mitarbeitende aus allen Fachbereichen, von „Copilot noch nie bewusst genutzt" bis „nutzt Copilot Chat regelmäßig" |
| **Vorkenntnisse** | keine; Programmierkenntnisse nicht nötig |
| **Sprache** | Deutsch |
| **Szenario** | Nordwind Consulting: Kundenprojekt „Hafenmodernisierung" und interner IT-Support |
| **Durchgehendes Ergebnis** | eigener Agent „Nordwind IT-Helfer" auf Basis der IT-Richtlinie |

Details zu Zielen, Voraussetzungen und Ablauf: [`m00-overview/overview.md`](m00-overview/overview.md).
