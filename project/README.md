# Projektdateien: Nordwind Consulting

Übungsdateien für alle Labs. Das Szenario und die Personen beschreibt [`szenarien.md`](szenarien.md). Alle Angaben sind fiktiv.

## Vor dem Start

1. Kopiere alle `.docx`- und `.xlsx`-Dateien in einen eigenen Ordner im eigenen OneDrive, z. B. `OneDrive/Copilot-Kurs/`.
2. Arbeite nur mit diesen Kopien. Copilot findet Dateien per `/` nur, wenn sie in OneDrive oder SharePoint liegen.
