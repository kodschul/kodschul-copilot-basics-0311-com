# Glossar

| Begriff | Bedeutung | Modul/Lab |
| ------- | --------- | --------- |
| `/`-Referenz | Eingabe von `/` im Copilot-Chatfeld fügt eine Datei, Mail, Besprechung oder Person direkt in den Prompt ein | Lab 1.2 |
| Agent | gespeicherter Spezialassistent in Copilot mit Name, Anweisungen und eigenem Wissen | Lab 5.1 |
| Agent Builder | Baukasten für eigene Agenten direkt in Copilot Chat, ohne Programmierung | Lab 5.2 |
| Aktion | Fähigkeit, mit der ein Agent in einem anderen System etwas erledigt, z. B. ein Ticket anlegen | Lab 5.3 |
| angedeutete Aufgabe | etwas wird erwähnt, aber niemand übernimmt es verbindlich | Lab 2.2 |
| Anweisungen (Instructions) | fester Auftrag an einen Agenten: Zweck, Quelle, Stil, Grenzen | Lab 5.1, 5.2 |
| Auffälligkeit (Ausreißer) | Wert, der deutlich vom üblichen Bereich abweicht | Lab 4.1 |
| besondere Kategorien personenbezogener Daten | besonders geschützte Angaben nach Art. 9 DSGVO, z. B. Gesundheit, Religion | Lab 6.1 |
| Bestätigung | der Mensch prüft und erlaubt eine Aktion, bevor der Agent sie ausführt | Lab 5.3 |
| Brand Kit | im Unternehmen hinterlegte Markenelemente, die Copilot auf Präsentationen anwendet | Lab 3.2 |
| Coaching | Copilot-Funktion, die einen eigenen Mailentwurf auf Ton und Klarheit prüft | Lab 2.1 |
| Ein-Prompt-Auftrag | ein ganzes Dokument mit einem einzigen Prompt erzeugen lassen | Lab 3.1 |
| Excel-Tabelle | als Tabelle formatierter Bereich mit Namen und eindeutigen Spaltenüberschriften | Lab 4.1 |
| Few-Shot / Zero-Shot | Prompt mit bzw. ohne Beispiel des gewünschten Ergebnisses | Lab 2.1 |
| Formel | Rechenanweisung in einer Excel-Zelle, z. B. `=SUMME(B2:B13)` | Lab 4.1 |
| freigegebenes Werkzeug | KI-Anwendung, Modell oder Erweiterung, die das Unternehmen ausdrücklich erlaubt hat | Lab 6.1 |
| Grounding | Copilot stützt die Antwort auf passende echte Inhalte, die zur Frage gesucht werden | Lab 1.1 |
| Halluzination | plausibel klingende, aber falsche Aussage eines Sprachmodells | Lab 1.1 |
| Human in the Loop (HITL) | der Mensch bleibt in jedem Schritt beteiligt und trifft die Entscheidungen | Lab 3.1, [Agentic Way](../m01-copilot-intro/00-nextise-agentic-way.md) |
| Kernbotschaft / Kernaussage | der eine Satz, den der Leser behalten soll / die eine Aussage eines Abschnitts | Lab 3.1 |
| KI-Richtlinie | internes Regelwerk eines Unternehmens für den KI-Einsatz | Lab 6.1 |
| Makro | gespeicherte Folge von Arbeitsschritten, die Excel auf Knopfdruck wiederholt | Lab 4.2 |
| MCP (Model Context Protocol) | offener Standard, über den KI-Anwendungen Werkzeuge anderer Systeme nutzen; „USB-C für KI" | Lab 5.3 |
| MCP-Server | Programm, das über MCP Werkzeuge eines Systems anbietet | Lab 5.3 |
| Microsoft Graph | Microsoft-Dienst, über den Copilot Mails, Termine, Chats und Dateien mit den Rechten der Person findet | Lab 1.1 |
| Nextise Agentic Way | Leitmotiv: Problem verstehen → Lösung konzipieren → Lösung bauen, Mensch in the loop; KI nutzen, um KI zu bauen | [Hintergrund](../m01-copilot-intro/00-nextise-agentic-way.md), Lab 3.1, 5.2 |
| personenbezogene Daten | alle Angaben, die sich einer bestimmten Person zuordnen lassen | Lab 6.1 |
| Prompt | Eingabe an Copilot: Frage, Auftrag und mitgegebene Angaben | Lab 1.1 |
| Prompt-Formel | Ziel · Kontext · Quelle · Erwartung | Lab 1.2 |
| Recap / Intelligent Recap | Registerkarte einer vergangenen Teams-Besprechung mit Transkript, KI-Notizen und Aufgaben | Lab 2.2 |
| Rückfragen zuerst | Prompt-Technik: Copilot stellt vor dem Schreiben Fragen | Lab 3.1 |
| Schritt für Schritt (Chain-of-Thought) | Prompt-Technik: Copilot zeigt den Lösungsweg in Zwischenschritten | Lab 4.1 |
| Sprachmodell (LLM, Large Language Model) | Programm, das aus riesigen Textmengen gelernt hat, Text fortzusetzen | Lab 1.1 |
| Sprechernotiz | Text unter einer Folie, den nur die vortragende Person sieht | Lab 3.2 |
| Startvorschläge (Starter prompts) | Beispielfragen, die beim Öffnen eines Agenten erscheinen | Lab 5.2 |
| Token | Textstück, mit dem ein Sprachmodell rechnet | Lab 1.1 |
| Training | einmaliger Lernvorgang eines Sprachmodells vor der Nutzung | Lab 1.1 |
| Transkript | automatisch erstellte Mitschrift einer Besprechung | Lab 2.2 |
| VBA (Visual Basic for Applications) | Programmiersprache, in der Excel-Makros geschrieben sind | Lab 4.2 |
| Werkzeug (Tool) | einzelne Aktion mit Name, Beschreibung und Eingabefeldern, die ein Agent aufrufen kann | Lab 5.3 |
| Wissen (Knowledge) | Dateien oder Seiten, auf die sich ein Agent stützt | Lab 5.1, 5.2 |
| Work IQ | Schaltfläche in Copilot Chat, die die eigenen Arbeitsdaten ein- oder ausschaltet; ersetzt die Registerkarten „Arbeit"/„Web" | Lab 1.1 |
| `.xlsm` | Excel-Dateiformat mit Makros | Lab 4.2 |
| zugesagte Aufgabe | eine Person übernimmt ausdrücklich etwas | Lab 2.2 |
