# Spickzettel

## Prompt-Formel

| Teil | Frage |
| --- | --- |
| **Aufgabe** | Was soll Copilot machen? |
| **Kontext** | Für wen und wofür? |
| **Quelle** | Welche Informationen soll Copilot nutzen? |
| **Ergebnis** | Wie soll die Antwort aussehen? |

## Prompt-Techniken

| Technik | Beispiel |
| --- | --- |
| Zielgruppe nennen | „für die Geschäftsführung“ |
| Ausgabeformat bestimmen | „maximal acht Stichpunkte“ · „als Tabelle“ |
| Schwerpunkt festlegen | „Konzentriere dich auf Budget und Termine.“ |
| Grenzen setzen | „Erfinde keine fehlenden Angaben.“ |
| Folgeprompt | „Formuliere das kürzer.“ · „Ergänze eine Empfehlung.“ |

## Qualitätsregeln für jeden Prompt

```text
Verwende nur Informationen aus der angegebenen Quelle.
Kennzeichne fehlende Angaben.
Erfinde keine fehlenden Angaben.
```

## Prüf-Checkliste

- Zahlen: Stichprobe nachgerechnet
- Fristen und Termine: stehen so in der Quelle
- Namen und Zuständigkeiten: richtig
- Verträge und Recht: fachlich geprüft
- Vertrauliches: nur an richtige Empfänger
- Lücken: gekennzeichnet, nicht erfunden

> **Merksatz:** Klar fragen, kritisch prüfen, verantwortungsvoll nutzen.
