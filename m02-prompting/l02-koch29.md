# Lab 2.2: Übung Koch29: ein Prompt für die Geschäftsführung

**Leitfragen:**

<details>
<summary>Was will eine Geschäftsführung über ein Projekt in zwei Minuten wissen?</summary>

Stand, Geld, Termine, Risiken und was sie entscheiden muss.

</details>

<details>
<summary>Welche Angaben in einem Projektbericht sind sicher, welche noch offen?</summary>

Sicher ist, was gemessen oder beschlossen ist. Offen sind Schätzungen, angekündigte Kosten und mögliche Verschiebungen.

</details>

## Übung Koch29

**Datei:** `Übungsblatt Koch29 für Promt und Outlook.docx` ([project/](../project/))

1. Öffne das Übungsblatt und lies die Ausgangsinformationen zum Projekt Koch29.
2. Formuliere einen möglichst guten Prompt für Copilot, um die Geschäftsführung über den aktuellen Stand von Koch29 zu informieren. Denke an Aufgabe + Kontext + Quelle + gewünschtes Ergebnis. Arbeite allein oder zu zweit (ca. 5–6 Minuten).
3. Prüfe den eigenen Prompt mit diesen Fragen:

| Prüffrage | ✓ |
| --------- | - |
| Ist die Aufgabe klar? | |
| Kennt Copilot Zielgruppe und Zweck? | |
| Ist die Quelle eindeutig? | |
| Ist klar, wie das Ergebnis aussehen soll? | |
| Könnte Copilot etwas falsch verstehen? | |

## Musterergebnis

<details>
<summary>Musterergebnis anzeigen</summary>

Copilot formuliert jedes Mal etwas anders; entscheidend ist, was enthalten ist.

**Musterprompt:**

```text
Erstelle auf Grundlage des Dokuments Koch29 eine kurze Zusammenfassung des aktuellen Projektstands für die Geschäftsführung. Konzentriere dich auf Projektfortschritt, Budget, Termine, Risiken und erforderliche Entscheidungen. Fasse das Ergebnis in maximal acht Stichpunkten zusammen. Stelle wichtige Zahlen und Termine deutlich heraus. Trenne bestätigte Informationen von noch ungeklärten Punkten. Erfinde keine fehlenden Angaben.
```

| Teil | im Musterprompt |
| ---- | --------------- |
| Aufgabe | kurze Zusammenfassung des Projektstands |
| Kontext | für die Geschäftsführung |
| Quelle | das Dokument Koch29 |
| Ergebnis | höchstens acht Stichpunkte, Zahlen und Termine hervorgehoben, bestätigt und offen getrennt |

**Beispielergebnis:**

- **Bestätigt:** 48 Wohnungen in Modernisierung, Beginn März 2026, ca. **70 %** fertig
- **Bestätigt:** Budget **2,4 Mio. €**, davon ca. **1,85 Mio. €** ausgegeben oder beauftragt
- **Bestätigt:** Elektroarbeiten ca. **drei Wochen** hinter dem Zeitplan
- **Offen:** Fertigstellung Ende Dezember 2026 gefährdet, möglich ist **Januar 2027**
- **Offen:** angekündigte Mehrkosten ca. **120.000 €**, noch nicht geprüft
- **Nächster Schritt:** genaue Kostenaufstellung bis **30.11.2026**
- **Entscheidung:** Budgeterhöhung ja oder nein, spätestens bis **05.12.2026**

</details>
